# Handwritten acknowledgments font

`Caveat-variable.ttf` is the unmodified Caveat variable font (weights 400–700),
bundled locally so personal acknowledgments do not depend on a font service.
It includes Latin, Latin Extended, Cyrillic, and Cyrillic Extended characters.

- Source: [Caveat upstream](https://github.com/googlefonts/caveat/blob/59745e818ef7973e11e70cb1358d0e902b56c5fc/fonts/variable/Caveat%5Bwght%5D.ttf)
