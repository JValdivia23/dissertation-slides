# Slide 30: synthetic wind-speed outlier detection

The four-click scene in `scenes/outliers.ts` uses the **original Paper 2
experiment**, precomputed in Python. Manim-web only displays the exported
samples; detection is evaluated on the complete 18 × 96 × 96 volume.

## Provenance and reproduction

- Paper repository: `DCT_paper2`, commit
  `c46edba5fc70581a2a727219916ac9aa79d0f932`.
- Numerical generator: `02_arXiv_Paper/scripts/generate_synthetic_validation.py`.
- Recorded metrics: `02_arXiv_Paper/results/synthetic_metrics.json`.
- Toolkit: `dct_toolkit` 0.5.0, commit
  `9d3b60ed408b5be819ae0eee0276c56840b712a7`.
- Python dependencies used for regeneration: NumPy 1.26.4, SciPy 1.13.1.

From this checkout, using a Python environment with those dependencies:

```sh
python scripts/export-outlier-animation.py \
  --paper-repo /path/to/DCT_paper2 \
  --toolkit-repo /path/to/dct_toolkit
```

The exporter reads the pinned Git objects, imports a temporary toolkit copy,
and runs the original numerical functions. The two source repositories are
read-only. It deliberately executes the earlier experiments that consume the
shared random generator: starting the outlier function directly with the same
seed would give a different realization.

All five seeds are checked against the recorded mean and sample standard
deviation of precision, recall, and F1 at k = 3, with absolute tolerance 1e-12.
The displayed realization, seed 20260414, has 526 injected anomalies and 445
detections: **406 TP, 39 FP, 120 FN**. Its individual scores differ from the
five-seed averages printed on the slide. The JSON records per-seed metrics,
source revisions, a generator SHA-256, and a hash of full-resolution arrays.

## Numerical and display conventions

- Gaussian noise standard deviation is 0.14 per component. Injection probability
  is 0.003, with random 3D directions and amplitudes uniform on [1.25, 2.25].
- Reflective Cartesian Gaussian widths are (3, 7, 7), in z, y, x order.
- The detector compares observed **speed** with `dct_mean(speed)` and
  `dct_std(speed)`. It does not compare vector residuals, or use
  `norm(dct_mean(vector))` as mean speed. The original 1e-6 standard-deviation
  floor is retained. This is a single-pass test with complete observations.
- The smoothed arrows show separately filtered u, v, w components. They explain
  the local reference flow; the speed test has its own scalar statistics.
- Display samples combine a regular sparse background, a deterministic sample
  of injection locations, all false-positive locations, and two inspected
  points. This is one fixed cohort through the overview stages. Display
  sampling does not enter any calculations or metrics.
- The close-up shows a detected injected point and a nearby ordinary point.
  Their exported, full-volume scores are 4.475043 and 0.171656. Horizontal bars
  share a 0–2.6 arbitrary-unit scale and show μ ± 3σ, μ, and observed speed.
- The scene uses an orthographic projection of 3D coordinates, with compressed
  height and display-scaled arrows for legibility. The enlarged neighborhood
  is a display crop; it is not a hard cutoff of the Gaussian kernel. Animation
  interpolates processing stages of a static field, not physical time.
- Red means known injected anomalies in stage 1. In the final stage, red means
  true detections, orange false alarms, and blue missed injections.
- Velocity-vector scoring is a possible extension, not an evaluated result.

The initial SVG is generated by the same projection as the Manim geometry.

navigation, leaving/re-entering, light/dark mode, and browser errors following
