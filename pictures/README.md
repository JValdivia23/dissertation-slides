# Acknowledgment photographs

- `acknowledgments-01.jpg` through `acknowledgments-42.jpg` are the original
  photographs, renamed in their original filename order without recompression.
- `acknowledgments-43.jpg` is the first frame of the original video, extracted
  at its native resolution of 478 × 850 pixels.
- `acknowledgments-43-source.mp4` preserves the original video unchanged.

`components/ThankYouPhotos.vue` automatically includes the still images in this
folder. Source videos and this README are not included in the photo collage.
